Privacy & Support – Strava Routes Downloader

Last updated: October 2025

Overview

Strava Routes Downloader is a community-focused application designed for members of a running club. The app connects to Strava to download routes created by the authenticated user, so that we can curate a shared library of running routes.

The purpose is to encourage more participation and variety of runs for members with curated choices of routes by start location, distance, and elevation.

This application is not commercial, will be used by a small group (around 20 people), and is intended to support a running community.

Data We Access

When you connect your Strava account, we request permission (via Strava’s secure OAuth flow) to access:

  • Route data (including ID, name, distance, elevation, start location, polyline, and associated route images).

We do not request or access your activities, health metrics, private segments, or follower data.

How Your Data Is Used

  • Route data is retrieved from Strava for the purpose of building a club route library.
  • The library will only include routes that start and finish at club-designated start locations.
  • No other routes (e.g., routes starting at or near your home) are included.
  • Route IDs are stored so members can link directly back into Strava to start a run.
  • Images and polylines may be used to show a visual preview or generate a GPX trail.

Data Storage & Retention

  • Routes are stored in a private library managed by the club.
  • We do not share or sell this data with third parties.
  • Data is retained only as long as the route library exists. If a route is removed, the corresponding data is deleted.
  • No personal identifying information is stored.

Security

  • All route data is retrieved through Strava’s official API using secure HTTPS.
  • Stored data is protected using standard security practices.
  • Only the small group of club curators (approx. 20 people) will contribute to the library and a smaller number will have access to the curated library.

Your Rights & Data Removal

  • You can revoke access to your Strava account at any time in your Strava account settings.
  • If you would like your data removed from the curated library, please email us at xroutesfinderfeedbackx@gmail.com.

Compliance

  • XRoutesFinder complies with the Strava API Agreement and Brand Guidelines.
  • We do not use Strava data for advertising, resale, or training of AI/ML models.
  • We only display data to authenticated users and within the context of the club route library.
